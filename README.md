# STONEBOTTRY

C++ bot framework for a privately controlled Metin2 test environment.

## Goal
Build a modular automation client with clear separation between game-state acquisition, targeting, movement, combat, inventory and configuration.

## Development order
1. Project/build system
2. Core runtime and logging
3. Client integration layer
4. Game-state abstraction
5. Targeting
6. Movement/combat
7. Pickup/potions
8. Configuration and UI

Use only with a client/server environment you own or are authorized to test.
